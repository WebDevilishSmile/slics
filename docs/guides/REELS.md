# Instagram Reels

The how-to videos posted on the app's Instagram, [@slics_app](https://www.instagram.com/slics_app/). A reel that matches a `/help` guide is linked from it: its URL is in `GUIDE_VIDEOS` (`components/help/guides.jsx`), and the guide ends with a "Watch it on Instagram" link. Post a new one, add it here, and add it there when a guide covers it. The scripts are in [`VIDEO-SCRIPTS.md`](VIDEO-SCRIPTS.md).
